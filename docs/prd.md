# 需求文档

## 1. 应用概述

### 1.1 应用名称
客户拜访管理系统

### 1.2 应用描述
一款面向销售团队的客户拜访全流程管理应用，支持拜访前背调资料搜集与PPT生成、拜访中录音采集、拜访后资料整理与报告查询，通过AI能力提升拜访效率与资料管理水平。

## 2. 用户与使用场景

### 2.1 目标用户
- 普通用户：销售人员，负责客户拜访的执行与资料记录
- 管理员：销售主管或团队负责人，负责查看团队拜访数据与系统管理

### 2.2 核心使用场景
- 拜访前准备：搜集客户背景资料，生成拜访用PPT
- 拜访中记录：通过录音实时采集拜访内容
- 拜访后整理：将录音转为文字稿，生成结构化报告并支持查询

## 3. 页面结构与功能说明

### 3.1 页面结构
```
├── 登录页
├── 注册页
├── 首页
│   ├── 拜访前准备
│   ├── 拜访中记录
│   └── 拜访后查询
├── 拜访前准备页
│   ├── 客户资料搜集
│   └── PPT生成
├── 拜访中记录页
│   ├── 录音功能
│   └── 上传录音文件
├── 拜访后查询页
│   ├── 报告列表
│   └── 报告详情
└── 管理后台
    ├── 用户管理
    └── 拜访数据统计
```

### 3.2 登录页
- 支持账号密码登录
- 提供注册入口

### 3.3 注册页
- 用户填写账号、密码、姓名等基本信息完成注册
- 默认注册为普通用户角色

### 3.4 首页
- 展示三个核心功能入口：拜访前准备、拜访中记录、拜访后查询
- 普通用户可访问全部功能
- 管理员额外显示管理后台入口

### 3.5 拜访前准备页

#### 3.5.1 客户资料搜集
- 用户手动输入客户基本信息（客户名称、行业、联系方式等）
- 系统通过搜索引擎或数据库自动获取客户背景资料
- 展示搜集到的资料供用户确认或补充

#### 3.5.2 PPT生成
- 基于搜集的客户资料，AI自动生成拜访用PPT
- 用户可预览生成的PPT
- 支持下载PPT文件

### 3.6 拜访中记录页

#### 3.6.1 录音功能
- 支持应用内直接录音
- 显示录音时长
- 支持暂停、继续、结束录音
- 录音结束后自动保存

#### 3.6.2 上传录音文件
- 支持上传外部录音文件
- 显示上传进度
- 上传成功后自动关联当前拜访记录

#### 3.6.3 拜访信息记录
- 用户填写拜访客户名称、拜访时间、拜访地点等基本信息
- 关联录音文件与拜访信息

### 3.7 拜访后查询页

#### 3.7.1 报告列表
- 展示所有拜访记录的报告列表
- 支持按客户名称、拜访时间、关键词进行检索
- 每条记录显示客户名称、拜访时间、状态（已整理/未整理）

#### 3.7.2 报告详情
- 展示拜访基本信息（客户名称、拜访时间、拜访地点等）
- 展示AI整理后的文字稿
- 展示AI归类整理后的结构化报告内容
- 支持查看原始录音文件

### 3.8 管理后台

#### 3.8.1 用户管理
- 管理员查看所有用户列表
- 支持修改用户角色（普通用户/管理员）
- 支持禁用或启用用户账号

#### 3.8.2 拜访数据统计
- 展示团队整体拜访数据（拜访次数、客户数量等）
- 支持按时间范围筛选统计数据
- 支持查看各用户的拜访记录

## 4. 业务规则与逻辑

### 4.1 用户权限规则
- 普通用户：可使用拜访前准备、拜访中记录、拜访后查询功能，仅能查看和管理自己的拜访记录
- 管理员：拥有普通用户全部权限，额外可访问管理后台，查看所有用户的拜访记录和数据统计

### 4.2 拜访记录流程
- 拜访前：用户搜集客户资料并生成PPT，系统保存客户资料
- 拜访中：用户录音或上传录音文件，填写拜访基本信息，系统关联录音与拜访信息
- 拜访后：AI自动将录音转为文字稿，并归类整理形成结构化报告，用户可查询和查看报告

### 4.3 AI处理规则
- PPT生成：基于客户资料，AI生成包含客户背景、行业分析、拜访建议等内容的PPT
- 录音转文字：AI将录音文件转换为文字稿，保留时间戳和说话人标识
- 报告整理：AI对文字稿进行归类整理，提取关键信息（客户需求、痛点、意向等），形成结构化报告

### 4.4 数据存储规则
- 所有客户资料、拜访记录、录音文件、文字稿、报告均需持久化存储
- 用户仅能访问自己创建的拜访记录，管理员可访问所有记录

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 客户资料搜集失败 | 提示用户搜集失败，允许用户手动补充资料 |
| PPT生成失败 | 提示用户生成失败，支持重新生成 |
| 录音时长过短 | 提示用户录音时长不足，建议重新录音 |
| 录音文件格式不支持 | 提示用户上传支持的录音格式 |
| 录音转文字失败 | 提示用户转换失败，支持重新处理 |
| 报告整理失败 | 提示用户整理失败，支持重新整理 |
| 查询无结果 | 提示用户未找到匹配的拜访记录 |
| 管理员删除用户 | 提示确认操作，删除后该用户无法登录 |

## 6. 验收标准

1. 用户可成功注册并登录系统，系统正确识别普通用户和管理员角色
2. 普通用户可在拜访前准备页手动输入客户信息，系统可自动搜集客户背景资料并展示
3. 系统可基于客户资料生成PPT，用户可预览并下载
4. 用户可在拜访中记录页进行录音，录音功能正常（暂停、继续、结束），录音文件自动保存
5. 用户可上传外部录音文件，系统正确关联录音与拜访信息
6. 用户填写拜访基本信息后，系统可保存完整的拜访记录
7. AI可将录音转为文字稿，并归类整理形成结构化报告
8. 用户可在拜访后查询页按客户名称、拜访时间、关键词检索拜访记录
9. 用户可查看报告详情，包括文字稿、结构化报告和原始录音
10. 管理员可在管理后台查看所有用户列表，修改用户角色，禁用或启用用户
11. 管理员可查看团队拜访数据统计，支持按时间范围筛选
12. 普通用户仅能查看和管理自己的拜访记录，管理员可查看所有记录
13. 所有异常情况均有明确提示，用户可根据提示进行操作
